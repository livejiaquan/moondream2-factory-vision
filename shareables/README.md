## Excluded on Purpose

The following remain local-only and should not be added to this folder:

- raw CCTV videos and still images;
- behavior source videos;
- historical run output folders with frame dumps;
- private AI Q&A or agent working notes;
- generated deck-builder workspaces and dependency folders;
- intermediate reports that were superseded by the files above.

The remote-internship Moondream report deck was found and preserved locally, but it is not committed because this repository is public and that deck contains company/person/CCTV details.
